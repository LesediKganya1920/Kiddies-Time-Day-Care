# Kiddies Time Day Care Centre

A responsive daycare website designed to help parents learn about Kiddies Time Day Care Centre and submit applications for available spaces online.

## 🎯 Project Purpose

The project was created to solve a real-world problem: replacing traditional paper-based applications with a simple online process that allows parents to access information and apply for a daycare space remotely.

## ✨ Features

* Responsive website design
* Daycare information and programmes
* Online application form
* Booking/application process
* Contact information
* Parent-friendly navigation
* Mobile-friendly layout
* Clear registration information

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## 💡 Problem Solved

Parents previously needed to rely on physical paperwork and in-person communication to apply for a daycare space.

This website provides a more convenient digital solution, allowing parents to access information and submit an application from different locations.
